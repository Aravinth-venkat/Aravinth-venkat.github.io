TRUSTED SOURCES

Prefer current, authoritative information.

How CareerLab should answer

  1. Prefer official documentation and official release notes.
  2. Use community sources only as supporting context.
  3. Show source links and freshness when current information is used.
  4. If reliable evidence is missing, say so instead of inventing an answer.
  5. Separate “what the technology does” from “how to explain your own experience in an interview.”
