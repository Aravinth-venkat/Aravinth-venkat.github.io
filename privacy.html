Resume privacy

Browser-first: your original PDF/DOCX is read in your browser and is not stored in a CareerLab database, GitHub repository, Cloudflare KV/R2, or permanent server folder.

AI mode: selected resume text is sent through the server-side Worker to the configured AI provider. The Worker does not intentionally persist the text. Requests use non-stored Responses where supported.

Important: an AI provider receives and processes text sent for analysis. Do not upload passwords, secrets, financial details or government IDs.

Delete: Delete Resume clears the file reference, extracted text, analysis, skills, interview state and resume-specific UI state from this browser session.
