PRIVACY

Resume privacy model

What CareerLab does

The PDF/DOCX is read in your browser. CareerLab does not intentionally upload the original file to GitHub Pages or save it in its own database. Resume text is held in JavaScript memory for the active page session.

When AI is enabled

The selected resume text is sent through the CareerLab server-side Worker to the configured AI provider so the requested analysis can be generated. Do not claim that the resume never leaves the device when AI mode is enabled.

Delete

Delete Resume clears the in-memory file name, extracted text, analysis, skills, interview history and generated resume-specific UI state. Reloading or closing the page also removes JavaScript memory.

What is not promised

This page does not promise zero retention by third-party providers. Provider retention and account-level data controls are governed by the provider's current policies and your account configuration.
