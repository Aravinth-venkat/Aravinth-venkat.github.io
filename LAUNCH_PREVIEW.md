# CareerLab Launch Preview

This build intentionally provides full Pro Preview access.

### Disabled for now
- Sign in / sign up
- Email authentication
- OTP / password recovery
- Subscription checkout
- Payment verification
- Free/Pro usage restrictions

### Enabled
- Resume PDF/DOCX upload
- Resume analysis
- CareerLab Explorer
- Mock interviews
- English speech-to-text
- Learning Lab
- Job discovery links
- Reading Mode
- Night Mode

When production APIs and billing are ready, the account/payment layer can be switched back on.
