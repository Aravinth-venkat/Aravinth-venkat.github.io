# CareerLab Launch Preview

## Current launch mode
Visitor -> Full Pro Preview -> Learn -> Practice -> Jobs

No sign-in, subscription, payment verification, or payment API is required in this version. All CareerLab features are available without usage gates so users can fully evaluate the product.

## Later production flow
Visitor -> Limited trial -> Sign in -> Free account -> Feature limits -> Pro trigger -> Subscription -> Payment verification -> Pro dashboard.

The production account/payment layer can be re-enabled later without redesigning the core CareerLab experience.
