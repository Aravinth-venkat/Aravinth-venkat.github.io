# Aravinth V — Universal Portfolio

Files:
- `index.html` — responsive animated portfolio + ServiceNow AI knowledge assistant
- `404.html` — custom GitHub Pages 404 page with a playable network-runner mini game

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Responsive design
The site is designed to adapt fluidly to mobile phones, tablets, laptops, desktop monitors, large displays/TV browsers and compact touch screens. It uses responsive typography, flexible grids, safe-area spacing, touch-friendly controls and reduced-motion support.

## AI assistant
The included assistant is a browser-only ServiceNow knowledge assistant. It does not require a secret API key. It covers common ServiceNow topics and portfolio-specific questions.

For a true generative AI assistant, use a secure backend/serverless endpoint. Never place an AI provider secret key directly in the public `index.html`.
