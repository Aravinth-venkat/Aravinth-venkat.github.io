# Aravinth V — Portfolio

Personal portfolio website for Aravinth V, ServiceNow Developer.

## GitHub Pages

Repository name:
`Aravinth-venkat.github.io`

In GitHub:
1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Branch: **main**
4. Folder: **/(root)**
5. Save

The website entry file is `index.html`.

## AI Portfolio Agent

The included assistant is a free, browser-only portfolio assistant. It answers from a small built-in knowledge base and does not expose any API key.

For a true generative AI agent later, connect a secure serverless/backend API. Do not put an AI provider secret key directly in `index.html`.
