PRIVACY

Resume handling

CareerLab's browser-only resume mode reads PDF/DOCX files locally and keeps extracted text in JavaScript memory for the active page session. It does not intentionally write the resume to a CareerLab database, file store, cookie, localStorage or sessionStorage.

Deletion

The user can delete the resume immediately using “Delete resume now”. The page also clears its resume variables when the page is being unloaded.

AI processing

If an AI endpoint is enabled, the extracted text is sent to that AI service to generate the requested answer. That means “not stored by CareerLab” must not be advertised as “never leaves the device.” The UI should clearly tell users when AI processing is enabled. CareerLab can redact common email, phone and LinkedIn patterns before sending.

Important limitation

Browser memory is not a permanent workspace. A refresh, crash, browser kill or navigation may remove the resume before the user finishes. For a future multi-page workflow, keep the resume in memory in a single-page application rather than server storage.
