# Aravinth Career Lab

Upload this folder to the root of a new GitHub Pages repository.

Files:
- index.html
- 404.html
- assets/styles.css
- assets/app.js

This is a frontend starter. It includes career topics, mock interview practice, resume improvement, experience recovery guidance, project mapping, a simple diagram generator and a local mentor interface.

For production AI, accounts, persistent user data, resume uploads, notifications and realtime features, connect a secure backend. Never put private API keys in GitHub Pages JavaScript.
