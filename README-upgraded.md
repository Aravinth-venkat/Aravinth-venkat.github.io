Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## What's new
- Motion/reveal animations while scrolling
- Animated background and floating effects
- 3D hover card on desktop
- Scroll progress bar
- Premium responsive mobile design
- Improved AI chat UI
- ServiceNow knowledge assistant covering ITSM, CMDB, CSDM, ITOM, scripting, ACLs, GlideRecord, GlideAjax, Script Includes, Flow Designer, REST, Import Sets, Service Catalog, Virtual Agent and Now Assist

The AI assistant is browser-only and does not expose an API key. For a true generative AI backend later, use a secure serverless/API layer rather than placing a secret in the page.
